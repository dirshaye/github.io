LagWatch

  • Tech Stack: Golang, Linux, JavaScript, HTML5/CSS3.
  • Focus: Out-of-band PC lag triage, host observability, recovery support
  • GitHub URL: https://github.com/dirshaye/LagWatch
  • Built a lightweight single-host observability and recovery service in Go using concurrent collectors and a buffered-channel aggregator to capture CPU, memory, disk, and network telemetry with low runtime overhead.
  • Implemented real-time system monitoring REST APIs and SSE plus a mobile-first browser UI for out-of-band triage from phone or tablet when the desktop is degraded.
