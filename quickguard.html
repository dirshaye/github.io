QuakeGuard

  • Tech Stack: Java, Spring Boot, PostgreSQL, React
  • Focus: Seismic data integration, geospatial analytics, real-time alerts

Developed a Spring Boot backend integrating external seismic APIs with geospatial calculations and a PostgreSQL data layer optimized for real-time queries. Built a React frontend with interactive maps and visualizations, delivered via REST APIs and deployed as a fully containerized Docker application.
