Semayat Hotel

Live Demo ↗ (semayathotel.et) GitHub Repository ↗
  • Tech Stack: Cloudflare Workers, Cloudflare D1 (SQL), Cloudflare R2, JavaScript, Chapa API, VAPID Web Push, AfroMessage/Twilio SMS.
  • Focus: Edge serverless backend, real-time hotel booking engine, property management system (PMS), automated payment processing.
  • Live Demo: https://www.semayathotel.et
  • GitHub URL: https://github.com/dirshaye/semayat-hotel
  • Architected and deployed a full-stack hospitality platform and Property Management System (PMS) on Cloudflare Workers, routing SPA client assets and edge API endpoints with millisecond global response times.
  • Engineered a relational database layer using Cloudflare D1 with automated migration scripts to manage a 30-room live inventory, bookings, guest profiles, secure sessions, and financial audit logs.
  • Integrated Chapa Payment Gateway for seamless online guest transactions and configured Cloudflare R2 object storage for secure guest identification document uploads.
  • Implemented automated bilingual (Amharic & English) transaction-safe notifications via AfroMessage & Twilio SMS APIs for instant reservation confirmations and floor Wi-Fi credential dispatch, alongside VAPID Web Push notifications for the staff operations portal.
