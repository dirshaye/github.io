OmniPrice

  • Tech Stack: FastAPI, TypeScript, MongoDB, React, Docker, Terraform, AWS.
  • Focus: Dynamic pricing, asynchronous scraping workflows, cloud deployment
  • GitHub URL: https://github.com/dirshaye/OmniPrice
  • Built a FastAPI backend with MongoDB and RabbitMQ-based job queues to handle asynchronous competitor price scraping workflows.
  • Developed a React plus TypeScript dashboard that integrates directly with backend APIs for auth, products, competitors, pricing, and analytics.
  • Containerized services with Docker, provisioned AWS infrastructure using Terraform, and set up GitHub Actions CI/CD pipelines for repeatable builds and automated deployments.
