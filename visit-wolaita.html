Visit Wolaita

Live Demo ↗ (visitwolaita.com) GitHub Repository ↗
  • Tech Stack: React 19, Cloudflare Workers, Google Gemini API, JavaScript, CSS3, Vite.
  • Focus: Serverless edge computing, Generative AI assistant, multimodal virtual try-on, cultural tourism preservation.
  • Live Demo: https://www.visitwolaita.com
  • GitHub URL: https://github.com/dirshaye/visit-wolaita
  • Architected a responsive tourism platform using React 19, React Router 7, and Vite, engineering a zero-dependency design system with CSS custom properties, dynamic routing, and interactive media lightboxes.
  • Implemented a serverless edge backend on Cloudflare Workers integrating the Google Gemini API (gemini-3.5-flash-lite), leveraging prompt grounding and conversation history tracking to deliver real-time, context-accurate travel assistance.
  • Built "Dunguza AI", an interactive virtual try-on studio that processes client-side image uploads via HTML5 FileReader and Blob APIs, pipelining them to a generative vision model for real-time garment rendering.
  • Designed a bilingual internationalization (i18n) system supporting English and Amharic (Ethiopic script) with localStorage persistence, coupled with WCAG accessibility patterns and deterministic SVG placeholder rendering.
